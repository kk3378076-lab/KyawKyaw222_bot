# KyawKyaw222_bot

ဒီပရောဂျက်ကတော့ Python နဲ့ ဖန်တီးထားတဲ့ Bot ပရောဂျက်တစ်ခု ဖြစ်ပါတယ်။

## Features
- Python ဖြင့် ရေးသားထားခြင်း
- `vipbot_new.py` ဖြင့် ပင်မလုပ်ဆောင်ချက်များကို လုပ်ဆောင်ပေးခြင်း

## Installation & Usage
1. ပရောဂျက်ကို Download လုပ်ပါ သို့မဟုတ် Clone လုပ်ပါ။
2. လိုအပ်သော Libraries များကို Install လုပ်ပါ။
3. အောက်ပါ Command ဖြင့် Run ပါ:
   ```bash
   vipbot_new.py
